# 100 Days of Practical Python

Code-first version of a 100-day Python plan focused on software engineering interview readiness and building a strong portfolio.

**Goals**
- Deep Python fluency
- Strong problem-solving (DSA + clean code)
- 3–4 portfolio-quality projects
- Consistent Git habits

**Structure**
- Daily solutions and notes
- Small projects early on
- Larger portfolio projects later
- Interview practice problems

**Tech**
- Python 3.14
- Git + GitHub

This is an active learning log. Code quality and commit history matter more than perfection.
